<objective>
Close the single gap 01-VERIFICATION.md found: ROADMAP Success Criterion 5's timeout half is not actually enforced. The per-hop `AbortController` in `fetchWithValidatedRedirect.ts` is disarmed in a `finally` block the instant `fetch()` resolves — which, under Node's undici, is the instant response *headers* arrive, not when the body is received. `fetchSource.ts`'s `readBodyWithCap()` then drains the body with no signal and no time budget at all, bounded only by a 2MB size cap. An origin that answers with headers immediately and then drips one byte per second is therefore never aborted; the verifier reproduced exactly that, still pending at 12,000ms against a local drip fixture.

This plan gives the pipeline one continuous per-source time budget that spans connect, header arrival, every redirect hop, and the full body read — and proves it with a fixture route that reproduces the unmitigated branch. It also carries a positive control, because the failure mode of a careless fix is a guard that aborts every body read and still passes an all-negative suite.

Purpose: Success Criterion 5 and INGEST-03 both promise a per-source timeout that bounds a *slow* source. Today that promise is true only for an origin that never answers at all. 01-03-SUMMARY.md claimed this gap closed; the verifier called that an overclaim and reproduced the counterexample. This plan is where the claim becomes true.

Output: a continuous per-source budget, two new hermetic fixture routes, three new tests, and the existing 10-test redirect suite still green and untouched.

Scope discipline: this is a targeted bug fix. The only files edited are the two that contain the defect and the two test artifacts that must prove it. UI components, `normalize.ts`, `filterLookback.ts`, `getFrontPage.ts`, `sources.ts` and every other already-verified file are out of scope and must not be touched.

**MVP-mode note for the orchestrator:** `MVP_MODE` is on and ROADMAP records `**Mode:** mvp` for this phase, but Phase 1's `**Goal:**` line is not written in user-story form ("A single real source flows through the entire architecture..."). No user story is invented here. This is a gap-closure plan restoring an already-scoped success criterion rather than delivering new user-visible scope, so it carries no new story; if a story is wanted for Phase 1 retroactively, that is `/gsd mvp-phase 01`, not this plan.
</objective>
